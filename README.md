# E-Invoicing MVP

Electronic invoicing MVP: clients, products and invoices.

## Features

- Client and product management
- Invoice creation
- Neon serverless Postgres
- Authentication

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- Neon Postgres

## Getting Started

```bash
git clone https://github.com/ghostland-dev/facturation-electronique-mvp.git
cd facturation-electronique-mvp
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: eslint .
