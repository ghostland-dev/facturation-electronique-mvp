# E-Invoicing MVP

Electronic invoicing MVP: clients, products and invoices.

## Features

- Client and product management
- Invoice creation
- Neon serverless Postgres
- Authentication

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- Neon Postgres

## Getting Started

```bash
git clone https://github.com/ghostland-dev/facturation-electronique-mvp.git
cd facturation-electronique-mvp
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: eslint .

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fghostland-dev%2Ffacturation-electronique-mvp)

Click the button to deploy your own copy on Vercel in one step.

Set these environment variables in the Vercel project settings (see `.env.example`):

- `DATABASE_URL`
